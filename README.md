# INSA Command · versões

Canal de atualização do app **INSA Command** (Windows).

Este repositório contém **apenas os instaladores** publicados em [Releases](../../releases).
Nenhum dado de carteira, chave ou informação pessoal é publicado aqui:
os dados ficam só no computador do dono, em `%APPDATA%\INSA Command`.

O app instalado verifica este canal ao abrir e a cada 6 horas, baixa a versão nova em segundo plano
e pede para reiniciar.
